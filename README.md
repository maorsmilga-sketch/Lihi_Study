# ממלכת המילים - גרסה 1

קוד מקור למשחק React ו-TypeScript עצמאי.

## הרצה
נדרשת Node.js 20 ומעלה. בתיקיית הפרויקט:

```sh
npm install
npm run dev
```

ליצירת גרסת הפצה:

```sh
npm run build
npm run preview
```

## תכולה
15 סיפורים עם 75 שאלות; 40 הבנה, 40 קריאה וניקוד, 20 אוצר מילים, 20 רצף והסקה, 30 פיסוק, 10 כתיבה, 7 משימות כניסה. מפה, שלושה עולמות, שלושה אוצרות, רמזים הדרגתיים, משוב, התאמה נפרדת לפי מיומנות, מסך הורים, הגדלת טקסט, הקראה מותנית בקול עברי, גיבוי וטעינה.

`content.ts` הוא מאגר תוכן ניתן להרחבה. `engine.ts` אחראי לבדיקה, להתאמה ולרישום. `App.tsx` מכיל את המשחק ואת מסך ההורים. `ui.tsx` הוא מעטפת ההרצה המקומית והשמירה המקומית. הקוד שומר נתונים בדפדפן; אין שרת או סנכרון.

## בדיקות שבוצעו
בדיקת מנוע לכל 242 המשימות, מפתחות תשובה, מניעת תגמול כפול, ייצוא/ייבוא נתונים, גבולות גודל שמירה, התאמת קושי לכל מיומנות. בדיקה חזותית ב-320, 390 ו-1280 פיקסלים; משחק חי באבחון, סיפור מלא, משימות ניקוד, פיסוק וכתיבה; טעינת מצב לפני הסיום והגעה לסוף ההרפתקה. הדוגמאות המנוקדות נבדקו בהקשר ובמילונים; זו אינה עריכה לשונית מקצועית חיצונית.

## מגבלות
הכתיבה מקבלת משוב כללי, לא בדיקה לשונית אוטומטית. הקריאה המדויקת נמדדת באמצעות בחירת משמעות ומילה בהקשר, ולא בדיקת הגייה. יש שני קטעים קצרים מנוקדים במלואם; יתר הטקסטים מנוקדים חלקית או ללא ניקוד. הסיפורים מתארכים לפי המסע; ההתאמה האישית משנה בעיקר את סדר המשימות ואת רמת הסיוע, לא יוצרת סיפור חדש.

בגרסת הקישור הפתוח, אורח ללא התחברות צריך להוריד קובץ התקדמות כדי לטעון אותו שוב אחרי רענון. בגרסה העצמאית בקוד זה, localStorage שומר בדפדפן גם בלי חשבון, אך ניתן להימחק ואין סנכרון בין מכשירים. ההקראה תלויה בקול עברי שמותקן במכשיר. הטקסטים והאיור מקוריים; האיור הוא איור דמיוני.
